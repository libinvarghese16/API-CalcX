# Mobile design system

## Character

Professional, technical, calm, high-contrast, information-dense without appearing crowded, and suitable for office or field use.

## Typography

- Interface: Inter, bundled locally
- Measurements and results: IBM Plex Mono, bundled locally
- Body: 15–16 px
- Supporting text: 12–14 px
- Input values: 16 px minimum
- Section titles: 18–22 px
- Screen titles: 30–44 px depending on viewport
- Line height: 1.45–1.65 for explanatory content

## Interaction

- Minimum touch target: 44 px
- Visible focus states
- No result communicated only through color
- Sticky primary actions on compact screens
- Searchable full-screen selectors for long engineering lists
- Original reference guidance adjacent to calculations without copying standards text

## Layout

- Desktop/tablet: persistent navigation rail and two-column work areas
- Phone: compact header, single-column content, five-item bottom navigation
- Calculator: inputs and reference content followed by a visible result summary
- Light and dark modes use the same semantic hierarchy
