# API 510 spherical-shell parity baseline

Status: implemented as a typed, UI-independent engine and connected to the shared API 510 mobile workflow.

The engine reproduces the protected legacy spherical-shell required-thickness, MAWP, corrosion-rate, remaining-life, inspection-projection, and test-pressure calculations. It reuses the shared material catalog, Metric/U.S. customary adapter, build-year and previous-inspection-year calculations, and highlighted Auto/Manual override controls.

Automated cases cover the captured golden result and an invalid pressure basis. Confirmation against the owner's controlled standard edition and procedure remains required before report issue.
